# Noted

A lightweight notes app that lives in your Windows system tray. Capture thoughts instantly with a hotkey, attach photos and voice recordings, format text — all stored locally, no account needed.

---

## Download

**[⬇ Download Noted-Setup.exe](../../releases/latest)**

Just download, run the installer, and you're done. No Node.js, no runtime, no extra software.

---

## Features

- **System tray** — lives quietly in the tray, always one click away
- **Global hotkeys** — open a quick note or the full list from anywhere on your desktop
- **Rich text editor** — bold, italic, underline, strikethrough, text color, bullet/numbered lists, blockquotes, dividers
- **Multiple photos per note** — drag & drop, paste from clipboard, or pick from file dialog
- **Multiple voice recordings per note** — record audio directly in the app; add as many clips as needed
- **Full-text search** — find notes instantly as you type
- **Dark / Light theme** — switch in Settings
- **Launch with Windows** — optional auto-start in tray
- **100% local** — all data is stored on your computer, nothing is sent anywhere

---

## How to use

1. After installing, the **Noted** icon appears in the system tray (bottom-right corner)
2. Press **Ctrl+Alt+N** to open a quick note from anywhere
3. Press **Ctrl+Alt+L** to open the full notes list
4. Press **Ctrl+Enter** to save, **Esc** to close the quick note

---

## Hotkeys

| Action | Default shortcut |
|---|---|
| Quick note | `Ctrl+Alt+N` |
| Open note list | `Ctrl+Alt+L` |
| Save note | `Ctrl+Enter` |
| Close quick note | `Esc` |

All hotkeys can be customized in **Settings**.

## Data & Privacy

All notes, photos, and audio recordings are stored locally at:

```
C:\Users\<you>\AppData\Roaming\Noted
```

The app has no internet connection and sends nothing to any server.
You can open this folder anytime from **Settings → Open data folder**.
