# Noted — менеджер заметок

Лёгкое приложение для Windows, которое живёт в системном трее. Записывайте мысли мгновенно по горячей клавише, прикрепляйте фото и голосовые записи, форматируйте текст — всё хранится локально, никаких аккаунтов.

## Возможности

- **Системный трей** — живёт в трее, всегда под рукой одним кликом
- **Глобальные горячие клавиши** — открыть быструю заметку или полный список из любого места на экране
- **Форматирование текста** — жирный, курсив, подчёркивание, зачёркивание, цвет текста, маркированные и нумерованные списки, цитаты, разделители
- **Несколько фото на заметку** — перетащите, вставьте из буфера обмена или выберите через диалог
- **Несколько голосовых записей на заметку** — пишите аудио прямо в приложении, добавляйте сколько нужно
- **Поиск по тексту** — находит заметки мгновенно по мере набора
- **Тёмная и светлая тема** — переключается в настройках
- **Автозапуск** — опционально запускается вместе с Windows
- **Всё локально** — данные хранятся на вашем компьютере, никуда не передаются

---

## Как пользоваться

1. После установки иконка **Noted** появится в системном трее (правый нижний угол)
2. Нажмите **Ctrl+Alt+N** — откроется окно быстрой заметки из любого места
3. Нажмите **Ctrl+Alt+L** — откроется полный список заметок
4. **Ctrl+Enter** — сохранить заметку, **Esc** — закрыть быстрое окно

---

## Горячие клавиши

| Действие | По умолчанию |
|---|---|
| Быстрая заметка | `Ctrl+Alt+N` |
| Список заметок | `Ctrl+Alt+L` |
| Сохранить заметку | `Ctrl+Enter` |
| Закрыть быстрое окно | `Esc` |

Все горячие клавиши можно изменить в **Настройках**.

## Данные и конфиденциальность

Все заметки, фото и аудиозаписи хранятся локально по адресу:

```
C:\Users\<имя пользователя>\AppData\Roaming\Noted
```

Приложение не имеет доступа в интернет и ничего никуда не отправляет.  
Открыть папку с данными можно в **Настройки → Папка с данными**.
